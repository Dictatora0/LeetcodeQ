# 14 - 模拟题题解

这一目录给 [90_minute_mock_set.md](../90_minute_mock_set.md) 中的 3 道模拟题提供完整教学型题解。

## 建议阅读顺序

1. 先独立完成 [90_minute_mock_set.md](../90_minute_mock_set.md)
2. 再按顺序看对应题解：
   - `problem_a_ranklist_solution.cpp`
   - `problem_b_longest_balanced_zero_one_solution.cpp`
   - `problem_c_zero_one_knapsack_solution.cpp`

## 使用建议

- 如果你是第一次做题：
  先只看题面，不看题解。
- 如果你已经做完但不确定：
  先看“核心观察”和“高频错误”。
- 如果你完全不会：
  先看模拟题单里的“推荐识别”，再回来看完整题解。
