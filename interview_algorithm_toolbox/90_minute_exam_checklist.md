# 90 分钟笔试模拟清单

这份清单用于笔试前最后 5 到 10 分钟快速过脑，不代替系统复习，只负责压缩决策流程。

配套模拟题单：
- [90_minute_mock_set.md](./90_minute_mock_set.md)

## 开题顺序

1. 先把 3 题都读完，不要读完第 1 题就马上写。
2. 先做“最稳能拿下”的题，通常是模拟、计数、排序、字符串、简单哈希。
3. 第二题优先考虑双指针、滑窗、二分、前缀和、简单贪心、基础 DP。
4. 第三题如果是规律题、位运算、图搜索、答案二分，先手推样例再动手。

## 时间分配

- `0 ~ 10` 分钟：读题、判断题型、决定顺序
- `10 ~ 35` 分钟：拿下第一题
- `35 ~ 65` 分钟：主攻第二题
- `65 ~ 82` 分钟：冲第三题或补前两题边界
- `82 ~ 90` 分钟：统一回查格式、边界、样例

## 第一眼识别

| 题面信号 | 优先考虑 |
| --- | --- |
| 统计个数、求最多最少 | 遍历、计数、贪心 |
| 区间和、多次查询 | 前缀和 |
| 子数组和满足模条件 | 前缀和 + 余数统计 |
| 有序数组、找边界 | 二分、双指针 |
| 连续子串、无重复 | 滑动窗口 |
| 合法前缀、括号、平衡 | `balance` 或栈 |
| 二进制、第 k 位、最低位 | 位运算 |
| 网格最短路 | BFS |
| 网格连通块 | DFS / BFS |
| 最小可行值、容量、速度 | 答案二分 |
| 每种物品可无限次选 | 完全背包 |
| 问方案数 | 计数型 DP |

## 开写前 20 秒自检

- 数据范围大概支持 `O(n)`、`O(n log n)` 还是只能做规律 / 数学
- 这题是单组还是多组
- 下标是 `0-based` 还是 `1-based`
- 是否需要 `long long`
- 输出的是值、下标、方案数，还是 `YES/NO`

## 高频稳分模板

- 模拟统计：
  一次遍历，顺手维护 `sum / min / max / count`
- 排序：
  先想清楚“比较器 true 到底表示什么”
- 哈希统计：
  先问自己是值域小用数组，还是值域大用 `unordered_map`
- 前缀和：
  先决定 `prefix[i]` 的定义，再写统一公式
- 双指针：
  先确认数组是否有序
- 滑动窗口：
  先确认元素是否非负，窗口和是否具有单调性
- 二分：
  先确认区间定义和单调性
- DP：
  先写状态定义，再写转移，最后看初始化

## 最容易混的 6 件事

1. `int` 溢出，尤其是前缀和、乘法、交叉相乘
2. 整数除法截断，例如 `1 / 2 == 0`
3. 比较器误写成 `<=` 或 `>=`
4. 多组数据忘记重置数组、哈希表、答案
5. 循环边界写错，访问 `a[i + 1]` 时还让 `i` 走到 `n - 1`
6. 输出格式不严谨，空格、换行、大小写出错

## 每题写完后的最小检查集

1. 样例能否过
2. 空数组 / 单元素是否会炸
3. 全相等 / 全奇数 / 全偶数 / 全负数这类极端情况是否考虑到
4. 最大数据下是否会超时或溢出
5. 是否有除零、空栈、空队列、越界访问

## 第三题卡住时的处理方式

1. 不要空耗 20 分钟硬顶。
2. 先写出暴力思路，看看样例里有没有规律。
3. 先问自己：是不是前缀和、位运算、周期、答案二分、BFS 这几类经典模式。
4. 如果仍不稳，优先回头把前两题边界和格式拿满。

## 最后 2 分钟

- 再扫一遍所有输出行
- 再看一遍是否用了 `long long`
- 再看一遍多测重置
- 如果有比较器，再看一遍是否严格
- 如果有二分，再看一遍边界是否会死循环
