# 13 - 高频错误清单

这一目录适合笔试前最后 10 分钟过一遍。

## 建议阅读顺序

1. `data_range_complexity_demo.cpp`
2. `int_overflow_demo.cpp`
3. `integer_division_demo.cpp`
4. `comparator_strict_order_demo.cpp`
5. `array_index_demo.cpp`

## 本目录重点

- 数据范围先决定算法复杂度，再决定实现
- `long long` 不只是“更大一点”，而是很多题的必要条件
- 比较器、下标、输出格式、循环边界、多测重置是基础题最常见丢分点
