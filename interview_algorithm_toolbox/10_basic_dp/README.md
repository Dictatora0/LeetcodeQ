# 10 - 基础动态规划

这一目录只放短期笔试最常考、最值得先掌握的一维 DP。

## 建议阅读顺序

1. `climbing_stairs.cpp`
2. `max_subarray_sum.cpp`
3. `lis_n2.cpp`
4. `zero_one_knapsack_basic.cpp`
5. `complete_knapsack_basic.cpp`
6. `coin_change_count_ways.cpp`

## 本目录重点

- 先写清状态含义，再写转移
- 一维 DP 经常能压缩成几个变量
- 最大子数组和和 LIS 是面试高频基础题
- 0/1 背包和完全背包最关键的差异，是容量循环方向
- 计数型一维 DP 最关键的差异，是初始条件和循环顺序
