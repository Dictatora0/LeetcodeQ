
# 滑动窗口模式指南

## 一眼识别信号（3 秒判断）
- 题目反复出现“连续子数组/子串”
- 目标是“最长/最短/个数”这类区间统计
- 暴力写法通常是双层枚举区间，复杂度 O(n^2) 或更高
- 题目允许你“右边扩张、左边收缩”，并且窗口状态可增量维护

## 常见题型分类
- 可变窗口：
  满足条件时收缩左边界，典型是“最短覆盖”“最长满足约束”
- 固定窗口：
  窗口长度固定为 `k`，每次滑动一步，典型是“长度为 k 的统计”
- 双约束窗口：
  例如“最多 K 次替换”“最多 K 个不同字符”，通常维护计数和违规量
- 单调队列窗口：
  窗口内还要维护最值（如窗口最大值），需要配合单调队列

## 选型速判：固定 vs 可变
- 出现“长度为 k”或“固定长度”：
  优先固定窗口
- 出现“最短满足条件”：
  通常可变窗口 + while 收缩
- 出现“最长且满足不超过某限制”：
  通常可变窗口 + 违规时收缩
- 出现“每个窗口求最大/最小”：
  固定窗口 + 单调队列

## 标准解题步骤
1. 定义窗口语义：
   `window = [left, right]` 表示当前考虑的连续区间
2. 选择状态：
   常见是字符频次、窗口和、不同元素个数、违规计数
3. 右指针扩张：
   加入 `nums[right]` 后更新状态
4. 左指针收缩：
   当窗口不合法时移动 `left` 并回滚状态
5. 更新答案：
   根据题意在“收缩前/收缩后”更新最值或计数

## 通用模板（可变窗口）
```cpp
int left = 0;
for (int right = 0; right < n; right++) {
    // 1) 加入 nums[right]，更新窗口状态

    while (窗口不合法) {
        // 2) 移除 nums[left]，回滚状态
        left++;
    }

    // 3) 更新答案（最长/最短/计数）
}
```

## 固定窗口模板
```cpp
int left = 0;
for (int right = 0; right < n; right++) {
    // 加入 nums[right]

    if (right - left + 1 > k) {
        // 移除 nums[left]
        left++;
    }

    if (right - left + 1 == k) {
        // 统计当前窗口
    }
}
```

## 高频易错点
- 先更新答案还是先收缩窗口的顺序写反
- `while` 误写成 `if`，导致窗口没有收缩到合法状态
- 频次减到 0 后忘记删除键，导致不同字符数统计错误
- 认为双层循环就是 O(n^2)，忽略左右指针单调右移的事实

## 和相似模式的区别
- vs 前缀和：
  前缀和擅长离线区间和查询；滑动窗口擅长在线维护“动态约束”
- vs 双指针：
  滑动窗口本质是双指针的一种，但核心在“窗口状态维护”
- vs 单调队列：
  单调队列是滑动窗口求最值时的增强组件

## 面试口述模板（30 秒）
- “这是连续区间最值问题，我用滑动窗口把暴力 O(n^2) 降到 O(n)。”
- “右指针负责扩张窗口，左指针在不满足条件时收缩。”
- “窗口内状态是 `xxx`，每次进出窗口都 O(1) 维护。”
- “两个指针都只向右移动，每个元素最多进出一次，因此总复杂度 O(n)。”
